# Итоговая работа — что уже закрыто и что добавить

Сверка проекта ПР6 (трекер привычек на Supabase) с требованиями итоговой работы.

## Оценка «3» — закрыто

| Пункт | Где в проекте |
| --- | --- |
| 8 связанных сущностей | `categories`, `tags`, `profiles`, `habits`, `habit_tags`, `check_ins`, `coupons`, `app_users` (`supabase/01-schema.sql`) |
| Связи один-к-одному / один-ко-многим / многие-ко-многим | купон ↔ профиль (1:1), категория → привычки, профиль → привычки и отметки (1:N), привычки ↔ теги (N:N) |

| Адаптив 360–1920 | `lib/core/layout.dart`, `lib/widgets/page_layout.dart` |
| Четыре состояния экрана | `lib/widgets/entity_list_screen.dart` (загрузка, данные, пусто, ошибка) |

## Оценка «4» — закрыто

| Пункт | Где |
| --- | --- |
| Регистрация и вход | `login_screen.dart`, `register_screen.dart`; в облачной версии пользователей создаёт администратор |
