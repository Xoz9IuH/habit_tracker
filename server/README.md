# Учебный сервер «Трекер привычек»

Node.js 18+. Внешних зависимостей нет.

## Запуск

```bash
node mock-server.js --port 8080 --origin http://localhost:5555
```

Клиент запускается на том же порту, который указан в `--origin`:

```bash
flutter run -d chrome --web-port=5555
```

Проверка: <http://localhost:8080/api/__health>.

## Учётные записи

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin123` | администратор |
| `librarian` | `librarian123` | редактор |
| `reader` | `reader123` | читатель |

## Проверка API

Во втором терминале:

```bash
node smoke-test.js
```

Скрипт проверяет коды 200/201/204, 401, 403, 404, 409, 422, права ролей, страницы, сортировку, поиск, связи 1:1, `?__delay`, `?__fail` и CORS. В конце данные сбрасываются.

## Возможности

- `POST /api/__reset` — вернуть исходные данные;
- `GET /api/__health` — состояние и количество записей;
- `?__delay=1500` — задержка ответа;
- `?__fail=500` — учебная ошибка.

Полное описание — в файле `../КОНТРАКТ-API.md`.
