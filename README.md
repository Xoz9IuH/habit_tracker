# habit_tracker — ПР 3: «Формы, валидация и связанные сущности»

Ветка `pr3` — продолжение проекта из ПР2 (в `master` лежит версия ПР2 со
списками, поиском, фильтрами и пагинацией).

Web-приложение на Flutter: личный трекер привычек с формами создания и
изменения записей, многоуровневой валидацией, пятью связанными сущностями
и сохранением данных между перезагрузками страницы.

## Что умеет

- **Пять сущностей со всеми тремя типами связей**: привычка (Habit),
  категория (Category), тег (Tag), профиль (Profile) и отметка о выполнении
  (CheckIn).
  - «многие к одному» — привычка → категория и профиль, отметка → привычка
    и профиль;
  - «многие ко многим» — привычка ↔ теги (список `tagIds`);
  - «один к одному» — профиль и его настройки, вложенные группой полей.
- **Формы создания и изменения** — один экран на сущность
  (`/habits/new` и `/habits/:id/edit`).
- **Валидация** каждого поля: обязательность, длина строки, диапазон чисел,
  формат почты, положительность, дата не в будущем. Валидаторы вынесены в
  `lib/validation/validators.dart` и переиспользуются между формами.
  Ошибка показывается под конкретным полем.
- **Уникальность** названий привычки, категории, тега и почты профиля.
- **Защита связанных записей**: удалить категорию, тег или профиль, на
  которые кто-то ссылается, нельзя — приложение сообщает число связанных
  записей.
- **Сохранение между перезагрузками** через `shared_preferences`
  (localStorage). Ключ хранилища содержит версию формата
  (`habit_tracker_habits_v2`): при смене версии данные переносятся, а при
  неудаче показывается сообщение и возвращается демо-набор.
- **Переиспользуемая форма**: `EntityForm` собирает поля по списку
  `FieldSpec`, разметка и отправка — общие для всех сущностей.
- **Каскад**: при выборе категории в форме привычки список доступных тегов
  сужается до тегов этой категории и общих.
- **PopScope**: предупреждение о несохранённых изменениях при уходе с экрана.

## Маршруты

| Адрес | Экран |
|---|---|
| `/habits` | Список привычек |
| `/habits?search=бег&categoryId=1&sort=streak,desc&page=2` | Список с фильтрами |
| `/habits/new` | Форма создания привычки |
| `/habits/:id` | Карточка привычки |
| `/habits/:id/edit` | Форма изменения привычки |
| `/categories`, `/categories/:id`, `/categories/new` | Категории |
| `/tags`, `/tags/:id`, `/tags/new` | Теги |
| `/profiles`, `/profiles/:id`, `/profiles/new` | Профили |
| `/check-ins`, `/check-ins/:id`, `/check-ins/new` | Отметки |
| unknown | 404 (`errorBuilder`) |

## Запуск

```sh
flutter pub get
flutter run -d chrome --web-port=5556
```

Для Android/iOS: подключите устройство или запустите эмулятор и выполните
`flutter run` (в Android Studio: **Run → Run**, в VS Code: **F5**).

## Проверки

```sh
flutter analyze
flutter test
flutter build web
```

## Структура

```
lib/
  main.dart                 точка входа, провайдеры, инициализация хранилища
  router.dart               фабрика маршрутов GoRouter
  data/seed.dart            демо-данные
  models/                   5 сущностей, запросы, PageResult, URL <-> query
  storage/json_store.dart   localStorage с версией формата и миграцией
  validation/validators.dart общие валидаторы полей
  forms/                    описание полей (FieldSpec) и общая форма (EntityForm)
  repositories/             контракты и реализации «в памяти» + хранилище
  state/                    ChangeNotifier'ы списков
  screens/                  списки, карточки, формы, 404
  widgets/                  таблица, список, пагинация, поле поиска
```

## Тесты

- `repository_test.dart` — сериализация, фильтры, поиск, сортировка,
  пагинация, корзина, уникальность, версия формата данных;
- `query_test.dart` — round-trip «объект запрос → URL → объект запрос»;
- `widget_test.dart` — отрисовка списка, форм, ошибок валидации.
