# habit_tracker — ПР 2: «Личный трекер привычек»

Web-приложение на Flutter: личный трекер привычек с прокачкой по МПТ (списки,
поиск, фильтры, сортировка, пагинация, выделение, удаление и восстановление).

Главная идея — **состояние живёт в адресной строке**: любой экран открывается
прямой ссылкой, а фильтры и страница восстанавливаются при перезагрузке.

## Что умеет

- **Список привычек** — таблица на широком окне, карточки на узком.
- **Поиск** по названию и цели (с задержкой 350 мс, чтобы не дёргать репозиторий).
- **Фильтры**: категория, периодичность, серия «от»/«до», показ удалённых.
- **Сортировка** по названию, серии и времени в день.
- **Пагинация** по 10/25/50 записей.
- **Выделение** нескольких привычек и массовое удаление в корзину.
- **Корзина**: мягкое удаление (`deletedAt`), восстановление, безвозвратное удаление.
- **Категории** — второй список со своей пагинацией, поиском и сортировкой.
- **Deep links** вида `/habits/3` и `/categories/2`.

## Маршруты

| Адрес | Экран |
|---|---|
| `/habits` | Список привычек |
| `/habits?search=бег&categoryId=1&sort=streak,desc&page=2` | Список с фильтрами и страницей |
| `/habits/:id` | Карточка привычки |
| `/categories` | Список категорий |
| `/categories/:id` | Карточка категории |
| unknown | 404 (`errorBuilder`) |

## Запуск

```sh
flutter pub get
flutter run -d chrome --web-port=5556
```

Для Android/iOS: подключите устройство или запустите эмулятор и выполните
`flutter run` (в Android Studio: **Run → Run**, в VS Code: **F5**).

## Проверки

```sh
flutter analyze
flutter test
flutter build web
```

## Структура

```
lib/
  main.dart                 точка входа, провайдеры
  router.dart               маршруты GoRouter
  data/seed.dart            демо-данные
  models/                   Habit, Category, запросы, PageResult, URL <-> query
  repositories/             контракты и реализации «в памяти»
  state/                    ChangeNotifier'ы списков
  screens/                  списки, карточки, 404
  widgets/                  таблица, пагинация, поле поиска с задержкой
```

## Проверки в тестах

- репозиторий: фильтры, поиск, сортировка, пагинация, корзина;
- `query_uri`:round-trip «объект запрос → URL → объект запрос»;
- виджеты: отрисовка таблицы, переход между экранами.
