# Трекер привычек — опубликованная сборка

В этой ветке лежит только результат сборки: GitHub Actions собирает Flutter-приложение
из ветки `pr6` и публикует файлы сюда. Ветка перезаписывается при каждом обновлении
исходников, вручную её править не нужно.

## Что где

| Ветка | Содержимое |
|---|---|
| `pr6` | исходный код приложения, сервер и отчёт |
| `gh-pages` | собранное приложение (эта ветка) |

## Как это работает

1. При изменении `pr6` запускается workflow `Deploy to GitHub Pages`.
2. Выполняются `flutter analyze`, `dart format --set-exit-if-changed`,
   `flutter test` — все три шага должны пройти.
3. `flutter build web --release --base-href /habit_tracker/` собирает приложение.
4. `index.html` копируется в `404.html`: GitHub Pages отдаёт его для неизвестных путей,
   поэтому прямые ссылки на внутренние экраны работают.
5. Файлы публикуются сюда, в ветку `gh-pages`.

## Ограничение GitHub Pages

GitHub Pages отдаёт только статические файлы. Интерфейс открывается, но запросы к API
(`/api/...`) обслуживать некому: статический сервер хостинга отвечает на них ошибкой
405 или 404. Поэтому вход и работа с данными доступны на учебном сервере:

```
node server-www/mock-server.js --port 8080
```

Этот сервер отдаёт и страницу, и API по одному адресу `http://localhost:8080`.
