## Что показывает ПР5

- регистрация с проверкой пароля по мере ввода (8 символов, буква, цифра, спецсимвол);
- вход, выход, сохранение сессии после перезагрузки;
- три роли с разными разделами, у каждой роли есть экран, закрытый остальным;
- маршруты защищены через `redirect`: чужая страница открывает экран 403;
- возврат на адрес, с которого отправили на вход (`?from=`);
- автоматическое обновление токена при 401 без участия пользователя;
- выход по неактивности 3 минуты с предупреждением за 30 секунд;
- проверка клиентской защиты: подмена роли в localStorage показывает кнопки, но сервер отвечает 403.

## Сервер: что добавлено в ПР5

| Метод | Адрес | Назначение |
|---|---|---|
| POST | /auth/register-strict | регистрация с усиленной проверкой пароля |
| GET | /users | список пользователей (только admin) |
| PUT | /users/{id}/role | смена роли (только admin) |
| DELETE | /users/{id} | удаление пользователя (только admin) |
| GET | /stats | статистика (только admin) |

Параметры запуска: `--ttl 60` для короткого access-токена, `--session 30` для ограничения сессии в минутах.
